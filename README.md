## Projetos em destaque

### [CheckPass](https://github.com/EmersonBayonetta/CheckPass)

Sistema full-stack para confirmação de presença e controle de entrada em eventos. Possui painel administrativo, links individuais para convidados, controle de acompanhantes, autenticação, API REST e persistência em PostgreSQL.

**Tecnologias:** Next.js, React, TypeScript e PostgreSQL.

### [Mini Loja](https://github.com/EmersonBayonetta/Trabalho-Mini-Loja)

Aplicação educacional de comércio eletrônico com catálogo, carrinho e checkout, desenvolvida para praticar testes de componentes e interações do usuário.

**Tecnologias:** Next.js, TypeScript, Jest e React Testing Library.

### [Aura Connect](https://github.com/EmersonBayonetta/aura-connect)

Interface SaaS que simula a conexão de uma conta WhatsApp Business, incluindo onboarding, validação, QR Code e estados visuais de conexão.

**Tecnologias:** React, TypeScript, Vite, Tailwind CSS e shadcn/ui.

### [Portal de Ferramentas](https://github.com/EmersonBayonetta/Portal-de-Ferramentas)

Portal modular que centraliza ferramentas de produtividade e gestão, com navegação por rotas, formulários tipados e estrutura preparada para novos módulos.

**Tecnologias:** React, TypeScript, React Router, React Hook Form e Zod.

### [Sistema de Biblioteca](https://github.com/EmersonBayonetta/Atividade-Sistema-Biblioteca)

Sistema para controle de livros, usuários, empréstimos e devoluções, com validações e regras de negócio implementadas por meio de APIs.

**Tecnologias:** Next.js, React, TypeScript e API Routes.

### [Task Manager](https://github.com/EmersonBayonetta/task-manager)

Base de um gerenciador de tarefas com integração ao Supabase e verificação do estado de autenticação do usuário.

**Tecnologias:** Next.js, TypeScript, Tailwind CSS e Supabase.
